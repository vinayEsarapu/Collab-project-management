# Collaborative Project Management & Issue Tracking Platform

A full-stack web application for collaborative project management and issue tracking.

The platform will allow teams to create projects, manage tasks, track issues, collaborate with team members, and monitor project progress.

## Project Purpose

The goal of this project is to build a real-world full-stack application using the MERN stack while following practical software development workflows.

The project will demonstrate:

- User authentication and authorization
- Project and team management
- Task management
- Issue/bug tracking
- Comments and collaboration
- REST API development
- MongoDB database integration
- Frontend and backend separation
- Git and GitHub workflow
- Testing and deployment

## Tech Stack :

### Frontend

### Backend
